# Protocol Definitions

This directory owns `.proto` source files and generated-code integration points.

`nexus_proto` links `protobuf::libprotobuf`, so public RPC typed APIs can use
any C++ class generated by `protoc`. Generated application sources will be
added to this target by TASK-015. Generated files belong in the build tree and
must not be committed into the source tree unless a later decision changes this
rule.
