# NexusRPC

NexusRPC is a C++17 distributed RPC framework with MCP integration.

The current repository is in Phase 0. This phase establishes project boundaries and build target placeholders. It intentionally does not install dependencies, validate the toolchain, or implement runtime behavior.

See:

- `docs/design.md` for the system design;
- `docs/development_decisions.md` for confirmed constraints;
- `docs/versions.md` for minimum tool and dependency versions;
- `docs/tasks.md` for executable implementation tasks.
